Removed "Comments after the last element field are lost" from [Known issues](known-issues.md) ([#293](https://github.com/neumaennl/xmlbind-ts/issues/293)) and narrowed "Comments between repeated elements move" to "Comments move when elements are reordered or dropped".

## 2026-11-10
* **Update**: [Known issues](known-issues.md#comments-after-the-last-element-field-are-lost): "Comments between and after repeated elements move or are lost" is split into "Comments after the last element field are lost" (High, S), which can be fixed on its own and links [#293](https://github.com/neumaennl/xmlbind-ts/issues/293), and "Comments between repeated elements move", which belongs to the order of elements; [Marshalling](marshalling.md#order-and-comments) links both.
* **Update**: [Marshalling](marshalling.md) describes that `marshal()` writes the document in the ordered mode of `fast-xml-builder`: comments are written without escaping, a comment that contains `--` or ends with `-` throws an error, a carriage return in a comment is read back as a line feed, `null` entries of arrays stay in their place, wildcard elements named like attributes or text throw an error, and the output starts with a line break. Removed "Comments are escaped and not checked" from [Known issues](known-issues.md) ([#292](https://github.com/neumaennl/xmlbind-ts/issues/292)), narrowed "`null` entries of arrays are written as empty elements", "Unmarshalling duplicates code for the root and nested elements" and "Source files are longer than 500 lines", found that comments after repeated elements can be lost, and added "Plain comment texts are dropped when mixed with comments that have a position", "Characters that XML does not allow are written" ([NaturalIntelligence/fast-xml-parser#902](https://github.com/NaturalIntelligence/fast-xml-parser/issues/902)), "The output of `marshal()` starts with a line break" ([NaturalIntelligence/fast-xml-builder#30](https://github.com/NaturalIntelligence/fast-xml-builder/issues/30)) and "Mixed content gets a line with only spaces" ([NaturalIntelligence/fast-xml-builder#31](https://github.com/NaturalIntelligence/fast-xml-builder/issues/31)). [Testing](testing.md) describes the helper `firstLine()` and the upstream tests, and [Architecture](architecture.md#modules) the tree that `marshal()` writes. The [development guidelines](development-guidelines.md) have new rules for where types are defined and for workarounds for problems in dependencies, and `AGENTS.md` tells agents to review changes themselves if Copilot code review is not available.
* **Update**: [Testing](testing.md#utilities-and-resources) describes the test class `Note` in `__tests__/test-utils/note.ts`. [Architecture](architecture.md#modules) says that `src/marshalling` also decodes entities and escapes values.
* **Update**: [Marshalling](marshalling.md#value-conversion) describes that `unmarshal()` decodes character references and the entities a DOCTYPE declares, except unsafe ones, and leaves HTML entities that XML does not define; a round trip writes character references as the characters they stand for, except carriage returns. [Architecture](architecture.md#dependencies) lists the new runtime dependencies `@nodable/entities` and `is-unsafe`. Removed "Character references are not decoded" from [Known issues](known-issues.md) ([#287](https://github.com/neumaennl/xmlbind-ts/issues/287)) and added "Invalid character references are removed without an error". [Marshalling](marshalling.md#marshalling) describes that `unmarshal()` keeps literal line feeds and tabs in attribute values and that `marshal()` writes carriage returns as character references, and [Known issues](known-issues.md) has the new entries "Line feeds and tabs in attribute values are not normalized" and "Comments are escaped and not checked" ([#292](https://github.com/neumaennl/xmlbind-ts/issues/292)).
* **Update**: [Decorators](decorators.md#when-to-review) has a new section "When to review": when the recommendation of legacy decorators and the way the tests compile decorators are reviewed. [#290](https://github.com/neumaennl/xmlbind-ts/issues/290) tracks the review; it is blocked by [oxc-project/oxc#9170](https://github.com/oxc-project/oxc/issues/9170) and relates to [neumaennl/vscode-visual-xml-schema-editor#434](https://github.com/neumaennl/vscode-visual-xml-schema-editor/issues/434).
